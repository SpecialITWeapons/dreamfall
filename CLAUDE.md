# Dreamfall

Working agreements for Claude Code and any other agent working in this repository.

## Language

- All source code, identifiers, code comments, commit messages, and the repository
  documentation (`README.md`, `AGENTS.md`, `CONTRIBUTING.md`, `VISION.md`) are written
  in **English**.
- Design specs and implementation plans under `docs/superpowers/` are written in
  **Polish**; that is the language the owner reviews them in.
- Conversation with the owner is in Polish; the code stays English regardless.

## Where the rules live

- `AGENTS.md` (created in M0, Task 10): the engine's rules for anyone changing `src/`.
- `docs/superpowers/specs/2026-09-14-dreamfall-design.md`: the approved design.
- `docs/superpowers/plans/`: one implementation plan per milestone.
